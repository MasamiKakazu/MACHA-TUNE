# MACHA-TUNE
音楽タイプ診断とおすすめ曲のシェアアプリのリポジトリです

公開用のビルドでは `MACHA_TUNE_PUBLIC_URL` にアプリの公開URLを設定してください。診断結果と楽曲発見の共有ページが、このURLを使って絶対URLのOGP画像を初期HTMLに出力します。サブパスで公開する場合は、同じパスを Vite の `--base` にも指定してください。

`npm run dev` の楽曲検索は同一オリジンのカタログ経路を使い、ビルド済みのアプリはブラウザーからAppleのAPIに接続します。外部検索に失敗すると、収録曲カタログから曲名とアーティスト名が一致する候補を表示します。録音IDの照合は `npm run dev` と `npm run preview` で同一オリジンの経路を使い、その経路がない静的ホスティングではブラウザーからAppleのAPIに接続します。
